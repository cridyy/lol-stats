# 定位判定

实现对应 `src/roleClassifier.ts`。定位的作用是回答“这局主要在承担哪类工作”，再把结果送入评分分支；它不是英雄的固定官方位置，也不是把所有英雄硬塞进 ADC、法师、战士、坦克、辅助五类。

## 可见定位

基础定位向量包含六种倾向：

```text
ADC、法师、刺客、战士、坦克、辅助
```

最终可能显示以下定位：

| 内部值 | 显示名称 | 说明 |
| --- | --- | --- |
| `adc` | ADC | 普攻、暴击和持续物理输出为主 |
| `mage` | 法师 | 法术输出为主 |
| `assassin` | 刺客 | 爆发和穿甲为主 |
| `fighter` | 战士 | 近战输出为主 |
| `tank` | 坦克 | 承伤和前排为主 |
| `support` | 辅助 | 治疗、护盾、功能和保护为主 |
| `bruiser` | 半肉战士 | 战士与坦克同时明显 |
| `pureAssassin` | 纯刺客 | 刺客倾向很高，坦克和战士倾向较低 |
| `fighterAssassin` | 战士刺客 | 战士与刺客同时明显 |
| `utilityCarry` | 功能输出 | 辅助倾向和远程输出倾向同时存在 |
| `unknown` | 输出 | 没有足够证据细分时的兜底 |

评分分支映射见[单局评分系统](scoring-system.md)：坦克进入前排，法师进入法师，战士/半肉战士/战士刺客进入战士，辅助进入辅助，其余进入输出。

## 两类证据

### 英雄自身标签

客户端英雄资源提供 `roles` 数组：

- 第一个标签权重为 `1.25`。
- 其余标签权重为 `0.85`。
- 最后归一化为英雄定位向量。

英雄标签描述“这个英雄通常能做什么”，不会因为一局装备变化而完全消失。

### 本局装备

装备定位综合三类信息：

1. 图标路径中的 `marksman`、`mage`、`assassin`、`fighter`、`tank`、`support` 等关键词。
2. 装备分类和描述中的暴击、攻速、普攻特效、穿甲、法强、法穿、生命值、护甲、魔抗、法力回复、治疗护盾强度等关键词。
3. `ITEM_FIXES` 手写修正表，用来修正游戏资源分类不准确或特殊装备的倾向。

装备不是简单一件一票，而是先按价格变成证据权重：

| 装备价格 | 计入定位证据的权重 |
| ---: | ---: |
| `<= 0` | `0` |
| `< 900` | `价格 × 0.20` |
| `< 1800` | `价格 × 0.45` |
| `>= 1800` | `min(价格, 3600)` |

小件、鞋子和消耗品会被稀释，成装才是“这局打算怎么玩”的主要证据。装备分类的关键词权重和特殊装备修正都集中在 `src/roleClassifier.ts`，调整时以代码表为准。

## 英雄和装备如何合并

装备越贵、倾向越集中，装备对本局定位的影响越大；装备证据不足时，更多相信英雄本身。

```text
装备主导度 = 装备定位向量中的最大值
```

装备总证据价值与主导度对应的装备占比：

| 条件 | 装备占比 |
| --- | ---: |
| 装备价值 `>= 4500` 且主导度 `>= 0.75` | `0.78` |
| 装备价值 `>= 4500` 且主导度 `< 0.75` | `0.65` |
| 装备价值 `>= 2200` 且主导度 `>= 0.80` | `0.72` |
| 装备价值 `>= 2200` 且主导度 `>= 0.65` | `0.62` |
| 装备价值 `>= 2200` 且主导度 `< 0.65` | `0.52` |
| 装备价值 `< 2200` 且主导度 `>= 0.85` | `0.55` |
| 其他有装备证据的情况 | `0.40` |
| 没有有效装备证据 | `0` |

```text
英雄占比 = 1 - 装备占比
最终定位向量 = 装备定位向量 × 装备占比
             + 英雄定位向量 × 英雄占比
```

### ADC 装备的安全门

如果英雄资源的前两个标签都不是 `Marksman`，装备侧的 ADC 倾向会被移除。这样，非 ADC 英雄即使出了暴击、攻速或部分普攻装备，也不会仅凭装备被错误判成 ADC；过滤后若装备侧没有其他有效证据，则回到英雄定位向量。

这条限制只针对 ADC 误判，不会阻止英雄因为法师、战士、坦克或辅助装备而改变本局定位。

## 最终定位解析顺序

定位解析按下面顺序执行，先判断复合定位，再判断单一定位：

| 条件 | 最终定位 |
| --- | --- |
| `战士 >= 0.30` 且 `坦克 >= 0.24` | 半肉战士 |
| `战士 >= 0.28` 且 `刺客 >= 0.24` | 战士刺客 |
| `刺客 >= 0.46` 且 `坦克 < 0.16` 且 `战士 < 0.26` | 纯刺客 |
| `辅助 >= 0.38` 且 `ADC/法师/刺客/战士最高值 < 0.42` | 辅助 |
| `辅助 >= 0.28` 且 `ADC/法师最高值 >= 0.28` | 功能输出 |
| `坦克 >= 0.42` 且 `战士 < 0.24` | 坦克 |
| 最高定位权重 `>= 0.22` | 最高权重对应定位 |
| 其余情况 | 输出 |

因此“辅助底子但出了输出装”可能变成“功能输出”，而不是强行算纯辅助；“战士出了肉装”可能变成半肉战士；这些变化只影响评分分支和标签，不会修改原始对局数据。

## 定位置信度与解释

`confidence` 是最终定位向量的最高权重。界面和接口还保留：

- 装备与英雄各自的权重占比。
- 装备定位向量。
- 英雄定位向量。
- 英雄资源中的原始标签。

这使得“为什么这局被判成辅助/战士”可以从证据链解释，而不是只显示一个不可追溯的结论。

## 与全服评分的关系

全服基准不重新创造一套定位。辅助正式全服分首先使用本模块已经得出的最终定位；只有当最终定位为辅助时才接入全服数据。

为了衡量“辅助装让一个原生输出英雄承担了多少新增工作”，全服辅助分还会额外计算一次“只使用英雄标签、不使用本局装备”的原生分支。这个原生分支只用于选择比较基准，不会覆盖正式定位结果，详情见[全服基准](global-baselines.md)。

## 调整入口

常见调参位置都在 `src/roleClassifier.ts`：

- `ITEM_FIXES`：特殊装备的人工修正。
- 装备描述和分类关键词权重。
- 装备价格换算。
- 英雄/装备合并比例。
- 复合定位和单一定位阈值。
- 非 Marksman 英雄的 ADC 倾向过滤。

定位改变会连带影响评分分支、动态控制借权、称号池和玩家画像，因此修改阈值后应同时运行前端检查和评分测试。
