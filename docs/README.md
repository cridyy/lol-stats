# LOL Stats 文档

这里是评分、全服基准和称号规则的单一入口。规则按“计算顺序”拆开，避免把评分公式、定位判断和娱乐称号混在一份长文档里。

## 推荐阅读顺序

```text
评分流程
  -> 定位判定
  -> 单局评分
  -> 全服基准（仅辅助正式接入）
  -> 称号系统
  -> 玩家画像
  -> 校准记录
  -> 本机接口
```

## 一页看懂当前边界

| 问题 | 当前答案 |
| --- | --- |
| 正式评分是多少分 | `0-100`，按最终定位走输出/法师/战士/前排/辅助分支 |
| 全服数据影响谁 | 只有海克斯大乱斗中的辅助正式分；其他定位不变 |
| 全服分是多少 | 辅助固定 `0-25` 分；达到英雄全服水平拿 `15` 分，达到 `150%` 封顶 |
| 全服累计数据如何比 | 先转分均，再按 8/16/20 分钟折算 `0.6/1.0/1.1` |
| 碾压局何时启用 | 最多 16 分钟、完整等人数队伍、败方少于两座塔，且 K/D/伤害/推塔至少一个门控成立 |
| 称号会改分吗 | 不会；称号只描述对局，统计只使用正式分 |
| 一个对局能有几个称号 | 可以多个；当前展示随机抽一个，接口保留全部命中结果 |
| 称号在哪里显示 | 战绩横条、详细对局和实时最近战绩；悬浮/聚焦可查看全部称号和事实标签 |
| 国服称号门槛 | 海克斯大乱斗、正式分至少 `90`，主指标 `140%`、另一项 `120%`、综合 `130%`；输出路线修正伤转至少 `1.40` |

## 规则变更原则

改动评分时，先改[评分系统](scoring-system.md)，再检查定位和画像；改动称号时，只改[称号系统](title-system.md)和校准记录，不要把娱乐称号条件写进评分公式。任何阈值变化都应在[校准记录](calibration.md)中说明样本、理由和预期影响。
