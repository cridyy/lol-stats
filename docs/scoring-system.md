# 单局评分系统

本文只说明“这一局最终得到多少分”。定位如何得到、全服基准如何接入、称号如何命中，以及多局如何聚合，分别见：

- [定位判定](role-classification.md)
- [全服基准](global-baselines.md)
- [称号系统](title-system.md)
- [玩家画像](profile-system.md)

实现对应 `src/scoring.ts`。这不是 Riot 官方评分，也不是对每个英雄写死一套模板；它的目标是让海克斯大乱斗、极地大乱斗等团战模式中的表现可解释、可比较，适合“电子斗蛐蛐”。

## 先看结论

1. 每局先算基础指标，再根据英雄和装备得到最终定位。
2. 定位映射到输出、法师、战士、前排、辅助五个评分分支。
3. 各分支子分相加，得到 `0-100` 的基础分。
4. 短时严重碾压局可能进行受控校准：只修正容易被队伍强弱扭曲的占比，并给部分输出/战士/法师重新分配 KDA 权重。
5. 最终定位为辅助且有适用的英雄全服基准时，原辅助公式中的三项小分被一项 `0-25` 的全服分替代；其他定位不读取全服数据，不改变原评分。
6. 分数、评价、评分 tag 和娱乐称号在计算上仍有不同来源；展示层会把评分 tag 与娱乐称号合并为一个称号池，不要把称号反向当成评分输入。

## 计算流程

```text
RecentGame
  -> 基础指标 outputRatingMetrics
  -> 英雄/装备定位 analyzePlayerRole
  -> 评分分支 calculateRatingParts
  -> 碾压局校准（可选）
  -> 辅助全服分（可选）
  -> clamp 到 0-100 并四舍五入
  -> 评价与评分 tag
```

百分比在公式中使用 `0-1` 小数，例如 `25% = 0.25`。最终分数先限制在 `0-100`，再四舍五入为整数；画像和接口仍可保留更细的中间值。

## 基础指标

| 指标 | 计算方式 | 用途 |
| --- | --- | --- |
| KDA | `(击杀 + 助攻) / max(死亡, 1)` | 碾压局 KDA 权重和高表现保护 |
| 伤害占比 | `个人对英雄伤害 / 队伍对英雄伤害` | 输出份额 |
| 经济占比 | `个人金币 / 队伍金币` | 资源占用 |
| 原始伤转 | `伤害占比 / 经济占比` | 资源转化效率 |
| 修正伤转 | `伤害占比 / 修正经济占比` | 减少“高输出带来高人头经济”的误伤 |
| 人头占比 | `个人击杀 / 队伍击杀` | 击杀份额 |
| 参团率 | `(击杀 + 助攻) / 队伍击杀` | 团战参与 |
| 死亡占比 | `个人死亡 / 队伍死亡` | 死亡负担 |
| 承伤值 | `自我减免 + 实际承受伤害` | 前排和动态承伤 |
| 承伤占比 | `个人承伤值 / 队伍承伤值` | 承伤份额 |
| 每死承伤 | `(个人承伤 / max(个人死亡,1)) / (队伍承伤 / max(队伍死亡,1))` | 区分有效承伤和无脑送死 |
| 治疗占比 | `个人总治疗 / 队伍总治疗` | 基础辅助、前排辅助分 |
| 分均控制 | `控制次数 / 对局分钟数` | 控制质量的频率门槛 |
| 控制占比 | `个人控制次数 / 队伍控制次数` | 控制覆盖 |
| 控杀占比 | `个人控制后协助击杀 / 队伍控制后协助击杀` | 控制结果 |
| 控制转化 | `个人控制后协助击杀 / 个人控制次数` | 控制质量 |

这里的“控制次数”来自客户端的 `enemyChampionImmobilizations`。全服基准中的“控制时长”是 `timeCCingOthers` 秒，两者是不同字段，不能直接互换。

## 共享修正

### 修正伤转

击杀会带来额外金币。玩家既打出伤害又拿到人头时，经济高不应被完全视为“吃资源不干活”；但只会 K 头时不能享受同样保护。

```text
K头质量 = clamp01(1 - max(0, 人头占比 - 伤害占比) / 0.18)
有效人头占比 = min(人头占比, 伤害占比 + 0.04)
人头压力 = clamp01((有效人头占比 - 0.18) / 0.18)
人头经济减免 = 0.06 * 人头压力 * K头质量

修正经济占比 = max(
  经济占比 - 人头经济减免,
  经济占比 * 0.78,
  0.08
)
修正伤转 = 伤害占比 / 修正经济占比
```

### 伤转的死亡门控

高伤转可能来自“死得多、经济占比被动变低”。因此伤转先按区间转成分数，再按死亡风险保留一部分：

```text
原始伤转分 = clamp01((修正伤转 - 基础线) / 成长区间)
死亡压力 = clamp01((死亡占比 - 0.20) / 0.12)
死亡与伤害错位 = clamp01((死亡占比 - 伤害占比 - 0.02) / 0.12)
送死风险 = max(死亡压力, 死亡与伤害错位)
死亡保护 = clamp01((伤害占比 - 0.20) / 0.10)
保留比例 = clamp(1 - 送死风险 * (1 - 死亡保护) * 0.65, 0.60, 1)
最终伤转分 = 原始伤转分 * 保留比例
```

伤害占比达到 `20%` 后开始保护，达到 `30%` 时保护达到上限。最低保留 `60%`，避免一次高风险团战完全抹掉有效输出。

### 人头质量

```text
K头差 = max(0, 人头占比 - 伤害占比)
高表现保护 = clamp01((KDA - 3) / 4) * clamp01((伤害占比 - 0.24) / 0.12)
修正K头差 = K头差 * (1 - 高表现保护 * 0.65)
人头质量 = clamp01(1 - 修正K头差 / 0.18)
```

人头占比明显高于伤害占比时，人头质量下降；KDA 和伤害占比同时高时，系统会认为这是核心输出或碾压局中的合理收尾，减轻 K 头惩罚。

### 生存分

不同分支使用不同起扣线和成长区间，但计算形式一致：

```text
原始死亡惩罚 = clamp01((死亡占比 - 起扣线) / 成长区间)
死亡保护 = clamp01((伤害占比 - 0.20) / 0.10)
保护后死亡惩罚 = 原始死亡惩罚 * (1 - 死亡保护)
生存分 = 1 - 保护后死亡惩罚
```

这不是“只要不死就高分”：低伤害保命局没有高表现保护，真实承担输出的玩家才会获得死亡保护。

### 控制质量

控制不直接按控制时长计分，避免廉价减速等数据污染。当前质量公式为：

```text
分均控制 <= 1：控制质量 = 0

控制占比分 = clamp01(控制占比 / 0.30)
控制转化分 = clamp01(控制转化 / 0.30)
频率分 = clamp01((分均控制 - 1) / 2)
频率门控 = 0.40 + 频率分 * 0.60
控制基础盘 = 控制转化分 * 0.55 + 控制占比分 * 0.45

控制质量 = clamp01(控制基础盘 * 频率门控 * 0.70 + 频率分 * 0.30)
```

法师分支使用同一质量函数，但分均控制不超过 `1` 时法师控制质量直接为 `0`。法师的控制分是加分项，不是每个法师都必须完成的硬指标。

### 前排承伤质量

前排要扛得多，也要尽量扛得值：

```text
承伤占比分 = clamp01(承伤占比 / 0.30)
每死承伤分 = clamp01((每死承伤 - 0.55) / (1.10 - 0.55))
门控承伤占比分 = 承伤占比分 * (0.35 + 每死承伤分 * 0.65)
门控承伤质量 = 门控承伤占比分 * 0.70 + 每死承伤分 * 0.30
```

坦克无脑送死刷承伤不会稳定拿满分；每死承伤越好，承伤占比越有价值。

定位到评分分支的映射：

| 最终定位 | 评分分支 |
| --- | --- |
| 坦克 | 前排 |
| 法师 | 法师 |
| 战士、半肉战士、战士刺客 | 战士 |
| 辅助 | 辅助 |
| ADC、刺客、纯刺客、功能输出、输出、未知 | 输出 |

### 输出分支

适用于 ADC、刺客、纯刺客、功能输出和未知输出。

| 部分 | 满分或分池 | 说明 |
| --- | ---: | --- |
| 伤害/伤转/承伤/控制动态战斗分池 | 69 | 默认以伤害和修正伤转为核心，优质承伤或控制可借权 |
| 参团 | 8 | `8 × clamp01((参团率 - 0.45) / 0.35)` |
| 人头质量 | 9 | `9 × 人头质量` |
| 生存 | 8 | `8 × 生存分(起扣 0.20，区间 0.18)` |
| 经济效率 | 6 | `6 × 伤转死亡门控(基础线 0.75，区间 0.65)` |

动态分池的默认参数：伤害目标 `32%`，伤转从 `0.78` 起算、`1.40` 满分；承伤最多借 `20` 分，控制默认不可借权重。主定位为法师或英雄底子为辅助的功能输出，控制最多可借 `30` 分，具体仍需满足质量优势门槛。

### 法师分支

法师保留伤害和伤转核心；控制是加分项，不是必做项。

| 部分 | 满分或分池 | 说明 |
| --- | ---: | --- |
| 伤害/伤转/承伤/法师控制动态战斗分池 | 63 | 法师控制最多借 `30` 分 |
| 参团 | 14 | `14 × clamp01((参团率 - 0.45) / 0.35)` |
| 人头质量 | 9 | `9 × 人头质量` |
| 生存 | 8 | `8 × 生存分(起扣 0.20，区间 0.18)` |
| 经济效率 | 6 | `6 × 伤转死亡门控(基础线 0.75，区间 0.65)` |

法师动态池参数：伤害目标 `32%`，伤转 `0.78-1.40`，不单独给承伤借权；分均控制不超过 `1` 时控制质量为 `0`。

### 战士分支

战士既可以打输出，也可以靠高质量承伤承担前排工作；两条路线在同一分池里择优，不另造“输出职责”评分。

| 部分 | 满分或分池 | 说明 |
| --- | ---: | --- |
| 伤害/伤转/承伤/控制动态战斗分池 | 79 | 承伤最多借 `22` 分；满足条件的功能控制最多借 `30` 分 |
| 参团 | 8 | `8 × clamp01((参团率 - 0.43) / 0.37)` |
| 生存 | 8 | `8 × 生存分(起扣 0.24，区间 0.20)` |
| 人头质量 | 5 | `5 × 人头质量` |

战士动态池参数：伤害目标 `30%`，修正伤转 `0.72-1.35`，承伤目标占比 `27%`、目标每死承伤 `1.08`。承伤只有在承伤质量高于原本的伤害/伤转组合，且承伤占比、每死承伤都过启动线时，才会从战斗池借分。

### 前排分支

前排对应坦克定位，承伤是核心，但不完全忽略输出、治疗和控制。

| 部分 | 满分 |
| --- | ---: |
| 承伤质量 | 30 |
| 有效伤害/控制共享池 | 30 |
| 参团 | 15 |
| 死亡控制 | 10 |
| 定位匹配 | 1 |
| 效率 | 9 |
| 治疗 | 5 |

共享池先算：

```text
伤害分 = clamp01(伤害占比 / 0.24)
控制分 = 控制质量
伤害权重 = 30 * 伤害分 / (伤害分 + 控制分)
控制权重 = 30 - 伤害权重
```

没有伤害和控制表现时，共享池为 `0`。承伤质量使用上一节的门控公式；参团为 `15 × clamp01((参团率 - 0.42) / 0.38)`；效率使用伤转死亡门控，`0.65-1.20` 为成长区间；治疗为 `5 × clamp01(治疗占比 / 0.25)`。

### 辅助基础分支

这是未启用全服基准时的原辅助公式。启用全服基准后，见[全服基准](global-baselines.md)，只替换其中的参团、人头质量和有效伤害三个实际小项。

```text
保护值 = max(治疗占比, 承伤占比 * 0.75)
```

| 部分 | 满分 |
| --- | ---: |
| 参团 | 23 |
| 治疗 | 18 |
| 保护 | 14 |
| 有效伤害 | 13 |
| 死亡控制 | 9 |
| 经济克制 | 6 |
| 人头质量 | 7 |
| 控制 | 10 |

基础辅助评分仍然统一覆盖治疗、护盾、开团和承伤型辅助；不按“软辅/硬辅”另造一套定位。治疗和护盾在正式全服分中按当前英雄自己的全服构成分权，详见全服文档。

## 动态承伤与控制借权

输出、法师和战士的承伤/控制收益来自原有战斗分池，不会凭空增加总权重。

```text
伤害分 = clamp01(伤害占比 / 该分支伤害目标)
伤转分 = 伤转死亡门控(...)
承伤质量 = 承伤占比质量 * 0.65 + 每死承伤质量 * 0.35
非承伤战斗分 = 伤害分 * 伤害比例 + 伤转分 * (1 - 伤害比例)
```

承伤借权需要同时满足：

1. 承伤质量高于非承伤战斗分。
2. 承伤占比达到启动线。
3. 每死承伤达到启动线。

```text
承伤优势 = 承伤质量 - 非承伤战斗分
承伤占比门槛 = clamp01((承伤占比 - 启动线) / 成长区间)
每死承伤门槛 = clamp01((每死承伤 - 启动线) / 成长区间)
优势门槛 = clamp01(承伤优势 / 优势区间)
承伤借权 = 最高借权 * 三个门槛相乘
```

控制借权同样要求控制质量高于非承伤战斗分：

```text
控制优势 = 控制质量 - 非承伤战斗分
控制借权 = 最高借权
  * clamp01(控制质量)
  * clamp01(控制优势 / 0.45)
```

承伤和控制借权合计不超过该分支可分配战斗池；剩余部分继续按伤害比例和伤转比例计算。

## 碾压局校准

短时严重碾压会让队内占比失真：败方正常发挥的人可能因为队友更差而占比虚高，胜方平均分担输出又可能显得普通。校准只在证据充分时启用。

### 启用前提

必须满足：

1. 能识别完整的两支等人数队伍。
2. 对局时长不超过 `16` 分钟。
3. 败方推塔数小于 `2`；败方推了两座或更多塔，整局不算碾压局。
4. 以下至少一个门控命中：
   - K/D 门控：胜方领先至少 `6` 个人头，且胜方 K/D 至少 `1.30`。
   - 伤害门控：胜方伤害达到败方的动态门槛。
   - 推塔门控：败方零塔；或败方只有一座塔且首塔时间占对局进度超过 `75%`。

伤害门槛从 `115%` 开始，按双方阵容修正：胜方每多一名坦克降低 `10` 个百分点，每多一名辅助降低 `5` 个百分点；反之提高。阵容不完整时回退到 `115%`。

### 首个防御塔时间

`败方首塔进度 = 败方首塔时间 / 对局总时长`。

```text
败方推 0 座塔：最大 KDA 权重 = 35 分
败方推 1 座塔：最大 KDA 权重 = 35 × clamp01((进度 - 75%) / 25%)
败方推 2 座及以上：不是碾压局
```

因此败方在对局 `75%` 进度时才推掉第一座塔，KDA 可借权为 `0`；直到接近对局结束才推掉第一座塔，才逐渐接近 `35` 分。`16` 分钟局中 `12` 分钟推塔正好是 `75%`，不会获得 KDA 借权。没有首塔时间时，一塔局不启用该门控；零塔局不需要时间字段。

摘要没有败方首塔时间时，后端会在必要时从 SGP 详情时间线的 `BUILDING_KILL` 事件补取；仍取不到就保持缺失，不猜测。

### 队内占比和全场占比混合

只混合伤害、经济、人头、死亡、参团及由它们重新计算的修正伤转；承伤、治疗和控制仍保持原队内口径。

```text
全场标准化占比 = 个人数值 / 十人总值 * (全场人数 / 本队人数)
有效占比 = 原队内占比 * (1 - 混合权重)
         + 全场标准化占比 * 混合权重
```

碾压强度由 K/D 差或伤害差中较强的一项决定，再乘时长系数和经济差放大，最高只混入 `65%` 的全场占比，至少保留 `35%` 原队内评价。只命中推塔门控时不混合全场占比，只从伤害/伤转池中划出 KDA 权重。

### KDA 重分配和胜负保护

坦克与辅助不参与 KDA 重分配；输出、法师、战士允许从伤害/伤转战斗池中划出最多 `35` 分（具体上限由败方首塔进度决定）。KDA 质量为：

```text
KDA质量 = clamp01((KDA - 1) / 4)
KDA子分 = 实际KDA权重 * KDA质量
```

胜方会在 `0` 到允许上限之间以 `0.5` 分步长试算，选最终总分最高的方案；同分优先保留原始算法或更低 KDA 权重，因此胜方不会因为启用校准而掉分。败方使用允许的最大 KDA 权重，但最终分数不会高于原始分。

败方若原始伤害占比至少 `27%` 且原始伤转至少 `1.20`，会按两项进度获得失败抵抗保护；达到 `35%` 和 `1.45` 时，负向碾压修正可完全被抵消，但不会额外加分。

所有碾压校准对最终分数的变化仍限制在最多 `25` 分；胜负结果项最多贡献 `±3` 分。缺少完整队伍、超过 `16` 分钟、败方两塔或门控不成立时，评分完全回到原公式。

## 分数评价和颜色

评价只看最终分数，不读取称号：

| 分数 | 评价 | `level` |
| ---: | --- | --- |
| `90-100` | 通天代 | `excellent` |
| `80-89` | 小代 | `excellent` |
| `70-79` | 小有实力 | `good` |
| `60-69` | 普通人 | `average` |
| `40-59` | 小坑比 | `average` |
| `<40` | 大坑比 | `poor` |

产品语义上，`70-79` 是正常偏好的发挥，`80+` 才进入明显高光，`60-69` 是小正常人区间，`60` 以下通常已经比较拉跨。称号系统会在此基础上另行判断“这一局发生了什么”。

## 缺失值与回退

- 旧缓存缺少队友治疗或控制时长时，该全服指标保持缺失，不补成真实零。
- 字段存在且数值为零时，视为本局真实零表现。
- 全服文件缺失、损坏、版本不支持、英雄无基准或模式不是海克斯大乱斗时，辅助也回退基础评分。
- 输出、法师、战士、前排从不因为全服文件状态改变正式分。
- 所有不合法的比例、负值和无效时长都会在评分入口被限制或视为不可用。
