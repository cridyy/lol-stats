# 称号系统

称号是评分之外的“电子斗蛐蛐”层。它描述这一局的风格、结果和梗，不参与百分制计算，也不会反过来改变分数。

实现对应 `src/titles.ts`。

## 四种展示信息

一局可能同时有多个结果，代码将它们分成四层：

| 信息 | 含义 | 例子 |
| --- | --- | --- |
| 评分评价 | 只由最终分数决定 | 通天代、小代、普通人 |
| 评分 tag | 评分函数选出的一个行为标签 | 稳定火力、功能担当、控制之神 |
| 娱乐称号 | 本规则文件中命中的一个或多个梗 | 悲情英雄、木已成舟、国服最强某英雄 |
| 事实标签 | 直接可验证的同局事实 | 伤害全场第一、评分队内第一 |

本机接口中的字段：

```text
score.evaluation  评分评价
score.tag         评分 tag
score.title       当前随机展示的一个娱乐称号
score.titles      本局全部命中的娱乐称号
score.titleDetails  称号名称、层级、类别和命中理由
score.factTags    事实标签
```

没有命中任何娱乐称号时，`score.title` 回退为评分 tag；“没有娱乐称号”不代表这一局没有评分评价。

## 层级和随机显示

称号层级只影响展示时的抽取概率，不影响命中：

| 层级 | 权重 | 用途 |
| --- | ---: | --- |
| 神话 | 5 | 极少数顶尖或决定性表现 |
| 高光 | 4 | 明显高于常态的表现 |
| 特征 | 3 | 风格、职责或局面特征 |
| 普通 | 2 | 正常发挥或轻量梗 |
| 调侃 | 1 | 低分、错位或失败梗 |

同一局可同时命中多个称号。显示名从所有命中称号按层级权重抽取一个：

- 接口每次刷新、软件内显式刷新战绩或实时对局时重新生成随机种子。
- 同一个响应内，列表和详情使用同一个选择结果。
- 重新打开软件后模块重新初始化，选择结果会变化。
- 下拉加载更多不会重新抽签，已显示的对局不会因为分页而换称号。
- `titles` 和 `titleDetails` 保留全部命中结果，不会因随机显示而丢失。

## 战绩界面展示

历史战绩横条、详细对局列表和实时页的最近战绩分数格都会显示当前随机称号。鼠标移入或键盘聚焦分数格时，会打开同一张称号卡片，内容按以下顺序排列：

1. 英雄头像、K/D/A、KDA 和最终正式分数。
2. 当前抽中的称号。
3. 本局全部命中的娱乐称号；没有专属称号时显示“本局暂无专属称号”。
4. 可直接验证的事实标签，例如“伤害第一”“评分全场第一”。

辅助有可用全服基准时，卡片底部只显示一行“全服得分 `X/25` 分”；全服各项倍率仍保留在本机接口和评分详情数据中，不把卡片塞成指标报表。评分 tag、评分评价和称号仍然分开，称号不会进入长期统计或玩家画像。

## 判定共识

- 普通玩家在 `60-79` 分的正常发挥，应能看到普通或特征称号。
- `80+` 才进入高光称号的主要入口；`90+` 才允许“神话”和国服级称号。
- “少冰七分糖”是“玩得唐”的调侃，不是稳定发挥的夸奖。
- “悲情英雄”“女武神”“渡劫失败”都要求较高个人分数和明确的败方相对证据，不用 `65` 分这种普通线。
- 队友平均分低于 `45`、个人低于 `20` 只代表极端局或挂机/残缺数据，不作为常规称号的入口。
- 缺少同局十人快照时，只使用个人数据；依赖队友名次的称号会自动失效，不把缺失当作零分。

以下条件中的“分数”均指最终正式分数；“分均承伤”单位是每分钟承伤值；“分均控制”单位是每分钟控制次数。

## 英雄级“国服”称号

国服称号是动态生成的，不为 172 个英雄手写 172 条规则。它只在海克斯大乱斗生效，不改变正式评分。

### 通用门槛

必须同时满足：

1. 对局是海克斯大乱斗（队列 `2400` 或模式 `KIWI` / `STRAWBERRY`）。
2. 最终正式分至少 `90`。
3. 当前英雄有有效全服基准。
4. 至少有两项可比较的英雄全服数据。
5. 选定职责路线后：主指标至少达到英雄均值的 `140%`，另一项相关指标至少达到 `120%`，相关指标加权综合至少达到 `130%`。

这里的 `140%` 是“本局表现 ÷ 该英雄均值 = 1.40”，不是玩家百分位。

### 路线选择

| 最终定位 | 可用路线 | 主指标 |
| --- | --- | --- |
| ADC、刺客、纯刺客、功能输出、法师、未知输出 | 输出路线 | 分均对英雄伤害；辅助指标从伤害经济转化率、伤害占比、参团率、KDA 中选表现最好的一个 |
| 坦克 | 前排路线 | 分均承受伤害或分均自我减免；辅助指标从分均控制、参团率、分均伤害中选 |
| 战士、半肉战士、战士刺客 | 输出路线和前排路线都试算 | 取综合倍率更高且满足门槛的路线 |
| 辅助 | 治疗路线或护盾路线 | 比较该英雄全服治疗均值和护盾均值，较大的那项为主职责；另一项、控制、参团和伤害为辅助证据 |

辅助路线的治疗/护盾/控制权重按该英雄自己的全服均值构成加权，避免星妈等治疗型英雄因为护盾绝对值较小而被错误评成护盾主导。

### 倍率口径

累计值（伤害、承伤、减免、治疗、护盾、控制时长、金币、补刀）先换算成分均值，再应用 `8 分钟 0.6、16 分钟 1.0、20 分钟 1.1` 的时长折算；KDA、击杀、助攻、参团率、伤害占比、伤害经济转化率直接比较。

国服称号的比较始终使用当前英雄自己的基准，即使该局因为装备进入辅助正式分支，也不会改用辅助英雄池基准。

## 事实标签

事实标签不需要娱乐阈值，只要字段明确就显示：

- 伤害全场第一（否则若仅队内第一则显示伤害第一）。
- 承伤第一。
- 治疗第一。
- 伤转第一。
- 经济第一。
- 评分队内第一。
- 评分全场第一。

事实标签和娱乐称号可以同时出现。例如“国服最强某英雄”不意味着一定是伤害第一；“爹来了”则同时要求获胜、分数和核心事实。

## 缺失和顺序

- 队友均分、名次、对手均分相关称号，只在完整同局快照可用时判断。
- 全服倍率缺失时，普通称号仍照常判断；只有国服和依赖对应基准的辅助称号会失效。
- 标题规则按代码数组顺序评估，但不会因为先命中一个称号就停止，最终会保留全部命中结果。
- 称号不会改变评分，也不会写入长期统计分布；评分统计只使用正式评分。
