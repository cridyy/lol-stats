# 玩家画像与单英雄画像

实现对应 `src/playerProfile.ts`。画像只聚合调用方已经加载的对局，不会为了生成画像偷偷再请求战绩。它使用和战绩卡片相同的正式评分，因此辅助全服分启用后，辅助画像也会同步变化；输出、法师、战士、前排不受全服分影响。

## 玩家画像输出

`buildPlayerProfile` 返回：

| 字段 | 含义 |
| --- | --- |
| `games` | 有效对局数 |
| `overallScore` | 综合分 |
| `medianScore` | 单局分数中位数 |
| `highlightRate` | 分数至少 `80` 的加权比例 |
| `disasterRate` | 分数低于 `60` 的加权比例 |
| `volatility` | 分数标准差 |
| `mainRoleLabel` | 出现次数最多的显示定位 |
| `roleDistribution` | 各定位场次、胜场、占比、胜率 |
| `abilities` | 输出、前排、辅助三条能力线 |
| `tags` | 一个主画像标签和若干附加标签，最多 10 个 |

## 三条能力线

画像把单局最终定位收敛成三条能力线：

| 单局定位 | 能力线 |
| --- | --- |
| 坦克、半肉战士 | 前排能力 |
| 辅助、功能输出 | 辅助能力 |
| 其他定位（包括 ADC、法师、刺客、战士、纯刺客、战士刺客、输出） | 输出能力 |

每条能力线都会单独统计场次、综合分、中位数、高光率、战犯率、波动、平均伤害占比、平均伤转、平均承伤占比和平均治疗占比。普通战士和战士刺客仍归入输出能力线；半肉战士归入前排能力线，这是画像聚合规则，不会改变单局评分分支。

## 时间加权

统计页和玩家总览通常会包含 `100-500` 场。为了兼顾长期能力和近期状态，默认启用时间加权；实时战绩显式传入 `timeWeighted: false`，保持短样本均匀平均。

### 单局权重

按对局时间从新到旧编号 `i = 0, 1, 2...`：

```text
近期原始权重 = 2 ^ (-i / 20)
近期归一化权重 = 近期原始权重 / 所有近期原始权重之和
```

场次越多，近期部分最多占比越高：

```text
场次比例 = clamp(0.30 + 0.10 × log2(有效场次 / 50), 0.30, 0.55)
```

大致对应：100 场约 `40%`，200 场约 `50%`，400 场及以上封顶 `55%`。剩余权重均匀分给全样本，避免一小段连胜或连败完全覆盖长期表现。

### 活跃度门控

真实时间只决定“近期状态是否仍应生效”，不直接替代对局序号：

| 距最近有效对局 | 活跃度 |
| --- | ---: |
| `<= 7` 天 | `1` |
| `7-30` 天 | 从 `1` 平滑下降到 `0` |
| `>= 30` 天 | `0` |

最终近期混合比例为“场次比例 × 活跃度”。超过一个月没有新对局时，综合分退回全样本均值，不会把很久以前的状态伪装成当前状态。

## 综合分和统计口径

玩家综合分使用最终混合权重：

```text
综合分 = Σ(单局正式分 × 单局最终权重)
```

高光率和战犯率也使用同一组权重：

```text
高光率 = 分数 >= 80 的权重之和
战犯率 = 分数 < 60 的权重之和
```

中位数是所有有效单局分数的普通中位数，不使用时间权重；波动是按最终混合权重计算的分数标准差。

## 主画像标签

画像标签分为“主标签”和“附加标签”。主标签不是简单地统计所有文本出现次数，而是先选择分数段，再在该分数段内找出现最多的评分评价。

### 分数段保护

| 分段 | 条件 |
| --- | --- |
| 高分段 | `>=80` |
| 正常段 | `60-79` |
| 低分段 | `40-59` |
| 战犯段 | `<40` |

选择步骤：

1. 按最终混合权重累计每个分段。
2. `<40` 战犯段只有权重占比达到 `30%` 才有资格成为主分段。
3. 在有资格的分段里选择权重最高者。
4. 只在该分段内统计评分评价，选加权次数最多的文本作为主标签。

注意：画像面板的“战犯率”仍是 `<60`；`<40` 只是主标签的极端段保护，两者不是同一个统计口径。

## 画像附加标签

正面标签通常要求综合分至少 `65`，负面标签可根据长期错位表现单独出现。当前主要规则如下：

| 条件 | 标签 |
| --- | --- |
| 平均伤害占比 `<20%` 且平均修正伤转 `<0.95` | 毫无存在感 |
| 平均人头占比比平均伤害占比高至少 `8` 个百分点，且平均伤害占比 `<24%` | k头狗 |
| 平均参团率 `<52%` 且平均伤害占比 `<23%` | 开游戏的 |
| 平均经济占比 `>=24%` 且平均修正伤转 `<1.0` | 拿钱不干事 |
| 战犯率 `>=25%`，或战犯率 `>=18%` 且综合分 `<65` | 开游戏的 |
| 战犯率 `>0` 且综合分 `>=70` | 偶有拉胯 |
| 综合分 `>=65` 且波动 `<=9` 且样本 `>=8` | 发挥稳定 |
| 波动 `>=18` 且样本 `>=8` | 上下限很大 |
| 综合分 `>=65` 且平均死亡占比 `>=27%` 且平均伤害占比 `>=25%` | 浴血奋战 |
| 综合分 `>=65` 且平均承伤占比 `>=29%` 且平均伤害占比 `>=23%` | 半肉战神 |
| 综合分 `>=65` 且平均承伤占比 `>=29%`，或前排能力线占比 `>=35%` | 哪来的城墙 |
| 综合分 `>=65` 且平均治疗占比 `>=25%`，或辅助能力线占比 `>=35%` | 团队功能 |
| 综合分 `>=65` 且输出能力线占比 `>=65%` 且平均伤害占比 `>=24%` | `>=80` 为输出机器，否则稳定火力 |
| 有主定位 | 常用{定位} |

高输出标签还包括“大魔王、爆炸核弹、全场火力点、核心大 C、吃草挤奶”等，使用的伤害占比、修正伤转和经济占比阈值与[称号系统](title-system.md)中的评分 tag 保持一致。控制画像标签沿用控制转化、控制占比和分均控制的六级梯度；综合分在 `40-64` 时仍允许显示控制标签，避免真正打出控制的人被低分直接抹掉。

## 单英雄画像

`buildChampionProfiles` 先按英雄 ID 分组，再对每个英雄重新计算正式评分，输出：

- 场次、平均分、主定位。
- 评分评价作为代表标签。
- 标签分段（高分、正常、低分、战犯）。
- 高光率、战犯率。
- 平均伤害占比、平均伤转、平均承伤占比、平均治疗占比。

单英雄代表标签同样先选主分段，再在主分段内找加权出现最多的评分评价；不会因为一两场极端低分就覆盖长期高分表现。单英雄标签颜色跟随主分段，而不是跟随标签文字：高分金色、正常绿色、低分蓝色、战犯红色。

### 单英雄评分公式

单英雄平均分、中位数和主分段平均分都会保留。样本至少 `10` 场且玩家仍处于活跃期时，额外加入 `20%` 的近期衰减分：

```text
活跃且样本 >= 10：
单英雄分 = 全样本平均分 × 0.40
         + 中位数 × 0.25
         + 主分段平均分 × 0.15
         + 近期衰减分 × 0.20

样本不足或最近一局超过 30 天：
单英雄分 = 全样本平均分 × 0.60
         + 中位数 × 0.25
         + 主分段平均分 × 0.15
```

这里的“全样本平均分”是该英雄所有对局的普通平均；近期衰减分才使用纯近期权重。空英雄池返回 `样本不足`，不会伪造零分画像。

## 与实时战绩的关系

实时战绩只用当前模式筛出的短样本，并关闭时间加权；它会为每个玩家和当前所选英雄生成同一套画像字段。历史统计页则默认启用时间加权。两者分数差异通常来自样本范围和近期权重，而不是另一套评分公式。

## 代码入口

- `src/playerProfile.ts`：画像聚合、三条能力线、主分段保护和画像标签。
- `src/scoring.ts`：画像使用的正式评分。
- `src/titles.ts`：单局娱乐称号；画像不直接把娱乐称号当作主标签。
